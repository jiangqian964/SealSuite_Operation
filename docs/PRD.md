## 1. 产品概述

### 1.1 项目背景

随着企业数字化转型的加速，越来越多的业务系统需要与 SealSuite（飞连）进行集成。手动操作和定期检查已无法满足业务需求，需要一个自动化运营系统来：
- 定时同步 SealSuite 数据
- 自动执行运营任务
- 实时监控业务状态
- 生成业务报表

### 1.2 产品定位

**SealSuite 自动运营系统**是基于 Go 语言开发的企业级自动化运营框架，旨在通过对接 SealSuite API，实现业务数据的自动采集、处理和分析，为企业提供高效、可靠的自动化运营能力。

### 1.3 核心价值

| 价值点 | 描述 |
|--------|------|
| **自动化** | 减少人工操作，提高运营效率 |
| **实时性** | 定时同步数据，保持信息最新 |
| **可靠性** | 自动重试机制，确保任务执行 |
| **可扩展** | 模块化设计，易于添加新功能 |
| **可监控** | 完善的日志和状态管理 |

## 2. 产品目标

### 2.1 业务目标

1. 实现 SealSuite 数据的定时自动同步
2. 提供灵活的定时任务调度能力
3. 支持多种数据类型的采集和处理
4. 提供完善的日志和监控能力

### 2.2 技术目标

1. 构建高可用的自动化运营框架
2. 支持多平台部署（Linux/macOS/Windows）
3. 实现配置化管理，支持环境变量覆盖
4. 提供完整的部署脚本和运维工具

### 5.2 模块职责

| 模块 | 职责 | 文件路径 |
|------|------|----------|
| **config** | 配置加载和管理 | `internal/config/config.go` |
| **logger** | 日志输出和管理 | `internal/logger/logger.go` |
| **sealsuite** | SealSuite API 客户端 | `internal/sealsuite/client.go` |
| **scheduler** | 定时任务调度 | `internal/scheduler/scheduler.go` |
| **handler** | 业务逻辑处理 | `internal/handler/jobs.go` |
| **utils** | 通用工具函数 | `pkg/utils/http.go` |

### 5.3 核心数据流

```
配置文件 → config.Load() → Config 结构体
              ↓
    应用启动 → scheduler.AddJob() → 注册定时任务
              ↓
    定时触发 → handler.JobFunc() → 业务逻辑执行
              ↓
    API 请求 → sealsuite.Client.Get/Post() → HTTP 请求
              ↓
    响应处理 → CommonResponse → 数据解析和处理
              ↓
    日志记录 → logger.Info/Error() → 日志输出
```

## 6. 数据模型

### 6.1 配置结构

```go
type Config struct {
    SealSuite SealSuiteConfig  // SealSuite API 配置
    Scheduler SchedulerConfig  // 调度器配置
    Log       LogConfig        // 日志配置
    Server    ServerConfig     // 服务配置（预留）
}

type SealSuiteConfig struct {
    BaseURL    string  // API 基础地址
    AccessKey  string  // API 访问密钥 ID
    SecretKey  string  // API 访问密钥密码
    Timeout    int     // 请求超时时间（秒）
    RetryTimes int     // 失败重试次数
}

type SchedulerConfig struct {
    Enabled  bool    // 是否启用调度器
    Timezone string  // 时区设置
}

type LogConfig struct {
    Level      string  // 日志级别
    Filename   string  // 日志文件路径
    MaxSize    int     // 单个日志文件最大大小（MB）
    MaxBackups int     // 保留的旧日志文件数量
    MaxAge     int     // 保留旧日志文件的最长天数
}
```

### 6.2 API 响应结构

```go
type CommonResponse struct {
    Code    int         // 响应状态码，0 表示成功
    Message string      // 响应消息
    Data    interface{} // 响应数据
}
```

## 7. API 设计

### 7.1 SealSuite API 接口

| 接口 | 方法 | 路径 | 描述 |
|------|------|------|------|
| 获取用户列表 | GET | `/api/v1/users` | 获取用户列表数据 |
| 获取设备列表 | GET | `/api/v1/devices` | 获取设备列表数据 |
| 获取组织列表 | GET | `/api/v1/organizations` | 获取组织架构数据 |

### 7.2 客户端方法

| 方法 | 参数 | 返回值 | 描述 |
|------|------|--------|------|
| `NewClient(cfg)` | `SealSuiteConfig` | `*Client` | 创建客户端实例 |
| `SetMockMode(enabled)` | `bool` | `void` | 设置模拟模式 |
| `Get(path)` | `string` | `(*CommonResponse, error)` | 发送 GET 请求 |
| `Post(path, body)` | `string, interface{}` | `(*CommonResponse, error)` | 发送 POST 请求 |
| `Put(path, body)` | `string, interface{}` | `(*CommonResponse, error)` | 发送 PUT 请求 |
| `Delete(path)` | `string` | `(*CommonResponse, error)` | 发送 DELETE 请求 |

### 12.2 Cron 表达式说明

| 字段 | 含义 | 取值范围 |
|------|------|----------|
| 秒 | 分钟内的秒数 | 0-59 |
| 分 | 小时内的分钟数 | 0-59 |
| 时 | 一天中的小时数 | 0-23 |
| 日 | 月份中的日期 | 1-31 |
| 月 | 一年中的月份 | 1-12 |
| 周 | 星期几 | 0-6（0 表示周日） |

**示例：**
- `*/30 * * * *` - 每 30 秒执行一次
- `0 */5 * * *` - 每 5 分钟执行一次
- `0 0 * * *` - 每天凌晨执行一次
